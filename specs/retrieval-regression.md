# 检索与阅读定位验收标准

目标：智能检索保持关键词 BM25 与向量召回的混合方式；同一块同时命中两路时，两路排名贡献相加。点击结果定位到该块，文内查找有可见高亮，目录可跳到视口外标题。

## 必须通过

- 精确：单词、多词 AND、引号短语、文件名/路径/正文、类型/目录筛选；空白、标点、超长查询不崩溃。
- 混合：词面、语义、双路三类结果均有覆盖；双路得分等于两路贡献之和；相同两路名次的双命中高于单路；重复块只出一次，total 为唯一结果数且不随 limit 改变；排序可重复。
- 中文：简繁互通；文内智能查找忽略空白、全角半角、大小写。精确查找保留字面语义。
- 格式：MD、TXT、JSON、DOCX；索引保留格式和标题路径，JSON 不使用合成键名前缀定位源码。
- 导航：长 MD 中首/中/末标题、重复标题、标题 hash、纯语义结果、同词多段、重复片段 occurrence；TXT、JSON、DOCX 结果和目录。以真实文本 Range 的视口坐标验收，不能只断言 URL 或 scrollTop 变化。
- 高亮：MD/TXT/JSON/Word 全部命中可见，当前命中可区分，Enter 循环，清空/关闭/换词清除旧色；跨节点、跨行、重复与重叠词不崩溃；标题和侧栏不会误计入正文。
- 隔离与生命周期：测试使用临时数据目录、复制夹具；不改用户资料库和当前选库；增量更新/删除后无旧命中；不同资料库无串库。
- 明确区分确定性测试与真实模型质量评估。mock 向量只能验证管线和排序，不能宣称语义理解通过；真实模型题集记录模型/配置、逐题相关性和召回。

## 交付

固定夹具、可执行回归命令、从基础到复杂的测试矩阵，以及实际通过/失败/未执行证据。既有真实语料评估保留，缺少语料不得按通过计。
