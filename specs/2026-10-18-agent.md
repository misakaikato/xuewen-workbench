# 规格：智能助手（pi agent 集成，RAG v2 升级）

日期：2026-10-18 ｜ 状态：施工中（M1）
前置：specs/2026-10-18-rag.md 的 v2「OpenAI 兼容端点」升级为独立 agent 模块。

## 0. 决策（2026-10-18 主人定）

v2 从单轮 LLM 调用升级为 **pi agent**（@earendil-works/pi-coding-agent SDK 内嵌）驱动的独立模块：
多轮对话、工具调用（工作台能力）、skills 与 MCP（agentDir 资源目录）、系统管理与语料问答。

## 1. 架构

```
前端 /agent 聊天页 ──SSE── POST /api/agent/chat
                              │
              server/agent/manager.js（AgentHub）
                              │ createAgentSession（pi SDK）
        ┌──────────┬──────────┼──────────────┬─────────────┐
   workbench 工具(7)   skills/      mcp.json      models.json(端点)   sessions/
   (InlineExtension)  (agentDir)  (agentDir)    (由 llm 配置生成)   (pi 持久化+UI投影)
```

- **agentDir = dataDir/agent/**：与用户全局 ~/.pi 隔离。skills/ 放 SKILL.md 即被发现；
  mcp.json 按 pi mcp.md 格式手放即生效（管理界面 M2）；models.json 由「生成端点」配置
  （RAG 管理页）自动生成（provider=workbench，OpenAI 兼容）。
- **会话**：每会话一个 pi AgentSession（SessionManager.create(cwd, dataDir/agent/sessions)）；
  UI 投影（用户/助手文本、工具卡、引用）镜像存 conversations/<id>.jsonl 供加载；
  conversations.json 存元数据（标题/时间）。
- **工具**（InlineExtension + TypeBox schema，闭包持有 getLib/ragManager/事件总线）：
  search_corpus / rag_search / read_doc / list_files / corpus_status / rag_manage / open_doc
  （open_doc 经 SSE 推前端打开文档并定位）。
- **系统提示词**：systemPromptOverride = 工作台身份 + 引用纪律（答案须基于工具命中的语料，
  标注 [文件名]；语料无据时明说）。
- **SSE 事件**：delta(text) / tool_start{name,args} / tool_end{name,summary,isError} /
  open_doc{path,term} / done / error。abort 中断。

## 2. API

```
GET    /api/agent/status                     端点配置 + 会话列表
POST   /api/agent/chat        {sessionId?, text}   → SSE 流
POST   /api/agent/abort       {sessionId}
GET    /api/agent/session/:id               UI 投影历史
DELETE /api/agent/session/:id
POST   /api/agent/session                   新建（返回 id）
```

## 3. 前端

/agent 页（顶栏「智能助手」）：左会话栏（新建/删除/切换）+ 消息流（流式文本、工具卡
折叠显示参数与结果摘要、引用块点击跳转原文）+ 输入框（Enter 发送，生成中可停止）。
端点未配置 → 引导去 RAG 管理页。

## 4. 里程碑

- M1（本次）：AgentHub + 7 工具 + SSE + 聊天页 + 会话持久化；真机验证（本机 Ollama/LM Studio）
- M2：skills/MCP 管理界面；e2e（mock OpenAI SSE 端点的确定性脚本）
- M3：steering/多轮插入、compaction 展示、系统管理工具全集（重命名/移动等）

## 5. 风险与实测点

- pi 包 34MB 纯 JS 进 Electron（无原生依赖，预期直接可用；打包验证）
- 本地小模型的工具调用质量参差（qwen 系较好）；openai-completions 协议下 tool_calls 流式
- 端点 model 列表需与 baseUrl 匹配（models.json 只注册配置里填的 model）
