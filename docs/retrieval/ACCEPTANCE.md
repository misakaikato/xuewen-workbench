# 检索与阅读修复验收记录

本轮交互修复和确定性检索回归通过；整体检索质量验收仍打回：真实模型 11 题通过 9 题，且全仓 lint 有既有错误。不能把这轮结果写成全面验收通过。

## 已证实的根因

1. Markdown 阅读器仅渲染视口附近内容。远处 `coordsAtPos` 返回 null，旧滚动函数直接退出；TOC 点了不动，搜索块定位也可能回退到全文首个查询词。40 章夹具复现：点击第30章修复前 scrollTop=0，修复后 scrollTop=8372，标题顶部约104px。
2. 文内查找只改选区，没有全体命中装饰。TXT/Word/JSON 原路径甚至只滚到第一个包含词的节点，不统计、不高亮、不循环。现加入 CM 装饰和可跨行内节点的 DOM mark。
3. 索引构建丢掉 ext/name 元数据，MD/JSON 实际按纯文本切块；章节路径丢失。现保留扫描字段，JSON 使用原始源码片段，旧索引指纹变化时提示/触发重建。
4. Word 父级状态更新会重设 innerHTML，目录 id 与高亮丢失。现稳定正文组件，并在排版模式改变后通知阅读页刷新目录。
5. 语义补位与词面补位可能包含相同块，total 还受 limit 影响。现去重、固定候选计数；原有 RRF 两路贡献相加机制保留。

最初大 TXT 的探测曾错误地用父元素矩形判断定位失败。改用实际文本 Range 后确认该条定位正确；不把这个误判列入根因。
